## 🌌 简介

**AcaNova-Halo** 是一个专为学术人员设计的优雅 Halo 主题，适合研究人员、博士生、教师等创建个人学术主页。该主题基于 AcaNova-X 静态模板改造，完全适配 Halo CMS，支持在 Halo 后台直接配置和更新。

### 🆕 多成员支持（v1.1.0 新功能）

现已支持**多成员学术主页**功能！每个成员可以独立创建和维护自己的学术主页：

- ✅ **独立页面**: 每个成员有自己的独立页面和 URL
- ✅ **自助编辑**: 成员可以直接在 Halo 后台编辑自己的页面
- ✅ **多种身份**: 支持教师、博士后、博士生、硕士生、校友等不同身份
- ✅ **自定义配置**: 每个成员可以配置个人信息、研究方向、教育背景等
- ✅ **成员列表**: 自动生成成员列表页面，支持按身份筛选

**详细使用方法请查看**: [成员学术主页使用指南](MEMBER_GUIDE.md)

### 核心特性

- ✅ **即装即用**: 从 Halo 应用市场一键安装，无需手动配置服务器
- ✅ **可视化配置**: 所有个人信息、研究方向、社交链接等均可在 Halo 后台配置
- ✅ **动态内容管理**: 新闻、论文、荣誉等内容通过 Halo 的文章系统管理
- ✅ **多用户支持**: 每个用户可以创建独立的学术主页，互不干扰
- ✅ **响应式设计**: 完美支持桌面、平板和移动设备
- ✅ **优雅排版**: 精心设计的学术风格，专业而不失现代感

## 📦 安装方法

### 方法 1: 从 Halo 应用市场安装（推荐）

1. 登录你的 Halo 后台管理界面
2. 进入「外观」→「主题」→「安装」
3. 在应用市场中搜索 "AcaNova" 或 "学术主页"
4. 点击「安装」按钮
5. 安装完成后，点击「启用」

### 方法 2: 手动安装

1. 下载本主题的 Release 版本
2. 解压后将整个文件夹上传到 Halo 的 `themes` 目录
3. 在 Halo 后台「外观」→「主题」中找到 AcaNova
4. 点击「启用」

## ⚙️ 主题配置

安装并启用主题后，进入「外观」→「主题」→「AcaNova」→「主题设置」，可以配置以下内容：

### 1. 基本设置

- **网站标题**: 浏览器标签页显示的标题
- **姓名**: 你的中英文姓名（例如：Your Name | 您的名字）
- **职位/角色**: 例如：Ph.D. Candidate / 博士研究生
- **所属机构**: 你的大学或研究机构名称
- **电子邮件**: 联系邮箱
- **个人照片**: 上传你的个人照片（推荐 1:1 正方形）
- **个人简介**: 关于你的背景、教育和研究重点的介绍
- **招生/合作信息**: 显示在简介下方的高亮框，用于招生或寻求合作

### 2. 研究方向

- **研究愿景**: 你的研究目标和期望影响的高层次陈述
- **研究框架描述**: 描述你的研究方法或框架
- **研究兴趣列表**: 可以添加多个研究兴趣点
- **具体研究方向**: 添加具体的研究方向卡片，包括标题、图标和详细描述

### 3. 社交链接

配置你的各类学术和社交平台链接：

- CV/简历链接
- Google Scholar
- GitHub
- ResearchGate
- 个人博客
- ORCID
- LinkedIn

只有填写了链接的社交平台才会显示在主页上。

### 4. 联系方式

- **办公地址**: 你的办公室位置
- **办公所在大学**: 大学名称
- **城市/国家**: 城市和国家信息

### 5. 学术服务

添加你的学术服务经历，例如：

- 会议审稿人
- 期刊编委
- 教学助理
- 等等

每项服务可以配置标题、机构/会议、图标和描述。

### 6. 教育背景

添加你的教育经历：

- 学位（例如：Ph.D. in Computer Science）
- 大学名称
- 时间段（例如：2023 - Present）
- 论文/专业信息

### 7. 样式设置

- **强调色**: 主题的主要强调色（默认金色）
- **个人信息卡片位置**: 左侧或顶部
- **显示/隐藏板块**: 可选择显示或隐藏新闻、荣誉板块
- **显示数量**: 设置首页显示的新闻和荣誉数量

## 📝 内容管理

### 发布新闻/动态

1. 进入「文章」→「写文章」
2. 填写标题和内容
3. 发布后，文章会自动显示在主页的「新闻」板块
4. 最新的 5 条（可配置）新闻会显示在首页，点击「View All」查看全部

### 发布论文/出版物

由于 Halo 的文章系统不太适合结构化的论文数据，论文信息仍然通过 JSON 文件管理：

1. 编辑 `templates/assets/data/publications.json` 文件
2. 按照现有格式添加论文信息
3. 保存后刷新页面即可看到更新

**论文 JSON 格式示例**：

```json
{
  "title": "Your Paper Title",
  "authors": "Author1, Author2*, Author3",
  "conference": "Conference Name (CCF-A)",
  "year": "2024",
  "links": {
    "paper": "https://example.com/paper.pdf",
    "code": "https://github.com/username/repo",
    "project": "https://example.com/project"
  },
  "image": "path/to/image.jpg",
  "note": "Oral Presentation"
}
```

### 管理荣誉奖项

类似论文，荣誉信息通过 JSON 管理：

1. 编辑 `templates/assets/data/honors.json` 文件
2. 按照格式添加荣誉信息
3. 保存后刷新页面

**荣誉 JSON 格式示例**：

```json
{
  "title": "Award Name",
  "organization": "Awarding Organization",
  "year": "2024",
  "description": "Brief description of the award"
}
```

## 🔄 更新主题

当主题有新版本时：

1. 进入「外观」→「主题」
2. 找到 AcaNova 主题
3. 如果有更新，会显示「更新」按钮

## 📱 多用户使用场景

如果你正在使用 Halo 作为教研室的内部网站，多个用户都需要学术主页：

### 方案 1: 使用分类系统（推荐）

1. 为每个成员创建一个分类（例如：成员A、成员B）
2. 每个成员发布的新闻/文章归类到自己的分类下
3. 在主题设置中为不同成员配置不同的信息
4. 通过 URL 路径区分不同成员的页面

### 方案 2: 使用标签页功能

1. 为每个成员创建独立的自定义页面
2. 使用页面模板展示个人信息
3. 成员可以独立管理自己的页面内容

### 方案 3: 多站点部署

如果需要完全独立的学术主页：

1. 在 Halo 中创建多个站点
2. 每个站点使用 AcaNova 主题
3. 每个成员拥有独立的后台和域名

## 🌟 功能亮点

### 1. 结构化的个人资料和研究愿景

- **主动寻求合作标识**: 清晰地表明你的合作意向
- **宏观到微观的愿景**: 从大愿景到具体研究方向的层次展示

### 2. 动态新闻，富有人情味

- **手写风格**: 新闻板块使用独特的字体选择，区分"更新"和正式内容

### 3. 交互式和可视化的出版物

- **海报级别展示**: "Image"按钮可展开条目，直接在列表中显示海报或缩略图
- **智能高亮**: 内置 **Oral** 和 **Spotlight** 徽章，以及自动 **CCF 等级**集成

### 4. 美观的时间线和专业联系方式

- **优雅流畅**: 服务和教育经历以清晰的垂直时间线呈现
- **精致的联系卡片**: 平衡专业性和隐私的布局
